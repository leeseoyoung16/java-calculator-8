# java-calculator-precourse

## 📘 1주차: 문자열 덧셈 계산기

### 🔧 구현 기능 목록

1. **사용자 입력 처리**
    - 콘솔을 통해 문자열을 입력

2. **결과 출력**
    - 계산된 합계를 콘솔에 출력

3. **커스텀 구분자 판별**
    - 입력 문자열이 커스텀 구분자를 사용하는지 판별

4. **구분자 선언부 제거**
    - `//`로 시작하고 `\\n`으로 끝나는 커스텀 구분자 선언부를 제거하고 실제 계산 문자열만 추출

5. **커스텀 구분자 도출**
    - 선언부에서 커스텀 구분자만 추출

6. **식별자 문자인지 판별**
    - 숫자 및 구분자 외의 문자가 포함되어 있는지 검사

7. **입력 유효성 검사**
    - 입력 형식이 유효한지(숫자, 구분자만 포함되는지) 검증

8. **문자열 파싱**
    - 구분자를 기준으로 숫자들을 분리하여 리스트 형태로 저장

9. **합계 계산**
    - 분리된 숫자들을 정수로 변환 후 모두 더해 최종 결과를 반환

---

- Pattern과 Matcher를 사용해 커스텀 구분자를 정규식으로 한 번에 파싱
